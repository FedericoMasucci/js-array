# Esercizio 4

Date le temperature settimanali, trova il valore massimo, il minimo e calcola la media aritmetica delle sette giornate.

## Ragionamento
- Dichiariamo array delle temperature della settimana 
- Analizziamo tutto l'array per trovare il valore minimo e il massimo e in un altra variabile sommiamo ogni temperatura Finchè non terminano i valori dell'array
- Usciamo dal ciclo e calcoliamo la media
- Stampiamo MAX, MIN e MEDIA
