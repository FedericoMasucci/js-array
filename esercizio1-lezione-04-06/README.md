# Esercizio 1 Lezione 04/06

Dato l'array dei nomi `["Latte", "Pane", "Uova", "Riso", "Pasta"]` e quello delle quantità `[12, 0, 3, 25, 4]`, scorri gli array e stampa un avviso di "ESURITO" se la quantità è 0 o "Scorte basse" se è minore di 5.

## Ragionamento

- Dichiariamo array nomi ["Latte", "Pane", "Uova", "Riso", "Pasta"];
- Dichiariamo array qta [12, 0, 3, 25, 4];
- Scorriamo nell'array quando finchè non finiscono gli elementi di questi 
   - Stampiamo ESAURITO se la quantità è uguale a 0
   - Stampiamo SCORTE BASSE se la quantità è minore di 5
